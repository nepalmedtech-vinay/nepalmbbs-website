## ⚡ QUICK START (3 MINUTES)

### Step 1: Get Credentials (2 min)
```
1. Go to https://supabase.com
2. Sign up (free) → Create project
3. Copy: Project URL + Anon Key + Service Role Key
```

### Step 2: Update .env Files
```bash
# Backend
nano leadflow_backend/.env
# Paste your Supabase credentials

# Mobile  
nano leadflow_mobile/.env
# Paste same Supabase credentials
```

### Step 3: Create Database
```
1. Open Supabase console
2. SQL Editor → New Query
3. Copy-paste from: leadflow_backend/sql/001_init_schema.sql
4. Click "Run"
```

### Step 4: Run Everything
```bash
# Terminal 1 - Backend
cd leadflow_backend
npm run dev
# ✅ http://localhost:3000

# Terminal 2 - Mobile
cd leadflow_mobile
flutter run
# ✅ App launches on emulator/device
```

**Done! Your app is running! 🎉**

## 🆘 TROUBLESHOOTING

```bash

flutter pub get
flutter run -v
```

**Backend won't start:**
```bash
cd leadflow_backend
npm install
npm run dev
```

**Supabase connection error:**
```
✓ Check .env file has correct credentials
✓ Verify project is active in Supabase console
✓ Check internet connection
```

**API returning 500:**
```
✓ Check backend is running (npm run dev)
✓ Check Supabase credentials in .env
✓ Check database schema was created
```
